# Code of Conduct

## Our Standards

This is a data repository. Contributions are limited to:
- Pricing corrections with source URLs
- New model additions with accurate pricing
- Documentation improvements

Expected behavior:
- Provide source URLs for all pricing data
- Be accurate — wrong pricing data costs companies money
- Be respectful in issue discussions

Unacceptable behavior:
- Submitting false pricing data
- Spam or promotional content
- Harassment of maintainers

## Enforcement

Issues violating this policy will be closed without comment.
Repeat violations result in blocking.
